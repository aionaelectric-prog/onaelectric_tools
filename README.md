# Ona Electric — برنامج إدارة العِدَد والمعدات

برنامج ويب بالعربي والإنجليزي، فيه وضع فاتح وداكن، وبيستخدم **Google Sheets كقاعدة بيانات**، ومنشور على **Vercel** من GitHub.

## الملفات
| الملف | الوظيفة |
|---|---|
| `index.html` | واجهة البرنامج |
| `style.css` | الشكل + الثيم الفاتح والداكن |
| `i18n.js` | نصوص العربي والإنجليزي |
| `app.js` | منطق البرنامج والربط بجوجل شيت |
| `config.js` | رابط الـ Web App بتاع جوجل شيت |
| `apps-script/Code.gs` | الـ API اللي بيتحط جوه جوجل شيت + بيانات المعدات من ملف الإكسيل |

## المميزات
- الرئيسية: إجمالي العِدَد، المتاح، اللي مع الموظفين، الصيانة والعطل، المفقود، والمستهلكات اللي قربت تخلص.
- **صرف عِدَد بالسحب والإفلات** (Drag & Drop). تقدر تصرف كذا قطعة مرة واحدة بـ Ctrl + ضغط، والبرنامج بيطبع إذن صرف بفورم ثابت.
- **إرجاع عِدَد** مع تسجيل حالتها: سليمة، بها عيب بسيط، تحتاج صيانة، عطل، مفقودة. حالة العدة بتتحدث لوحدها، والبرنامج بيطبع إذن إرجاع.
- **المستهلكات**: نسبة المتاح % من كل صنف، والكمية اللي اتصرفت لكل مشروع.
- **التقارير**: فلترة بالموظف والنوع والمشروع والتاريخ، وتصدير Excel، وطباعة.
- زرار **عربي / English** وزرار **فاتح / داكن**، والاختيار بيتحفظ.

## الخطوة 1 — تجهيز جوجل شيت
1. افتح الشيت: https://docs.google.com/spreadsheets/d/17VkrYhr4uDPP0Fs2KNM56i_3tGuQC86-nO28gAWYLko/edit
2. من القائمة **Extensions (الإضافات) → Apps Script**.
3. امسح الكود الموجود، والصق محتوى `apps-script/Code.gs` كله.
4. في أول السطور غيّر `const ACCESS_KEY = 'CHANGE_ME';` لكلمة سر من عندك.
5. احفظ (Ctrl+S). اختار الدالة **setup** من فوق واضغط **Run**. أول مرة هيطلب صلاحيات: Review permissions ثم حسابك ثم Advanced ثم Go to … ثم Allow.
   - الدالة دي بتعمل 7 تابات: العدد، الموظفون، المشاريع، حركة الخروج والعودة، المستهلكات، حركة المستهلكات، الإعدادات. وبتنزّل **الـ 31 معدة** من ملف `نظام_إدارة_المعدات_والعهد_المتقدم.xlsx`.
6. **Deploy → New deployment →** النوع **Web app**:
   - Execute as: **Me**
   - Who has access: **Anyone**
   - اضغط Deploy وانسخ **Web app URL** (بيخلص بـ `/exec`).

## الخطوة 2 — ربط البرنامج
- **الطريقة الأولى:** حط الرابط في `config.js` داخل `API_URL: '...'` وارفعه على GitHub، فيبقى ثابت لكل الأجهزة.
- **الطريقة التانية:** من البرنامج روح للإعدادات، واكتب الرابط وكلمة السر، واضغط "ربط".
- **كلمة السر** بتتكتب مرة واحدة على كل جهاز من الإعدادات، وبتتحفظ على الجهاز ده بس، ومش بتترفع على GitHub.
- لما الربط ينجح هيظهر فوق "متصل بجوجل شيت".

## الخطوة 3 — GitHub و Vercel
1. ارفع الملفات دي على الريبو `aionaelectric-prog/onaelectric_tools`.
2. على https://vercel.com اعمل **Add New → Project** واختار الريبو. Framework: **Other**، ومن غير Build Command. ثم Deploy.
3. أي تعديل يترفع على GitHub، Vercel بينشره لوحده.

## لو عدّلت Code.gs بعد كده
Deploy → **Manage deployments** → اختار الـ deployment ثم ✏️ ثم Version: **New version** ثم Deploy. كده الرابط بيفضل زي ما هو.

## ملاحظات
- البيانات في الشيت مكتوبة بالعربي، وتقدر تفتحها وتراجعها. **ما تغيّرش عمود "المعرف"** ولا ترتيب الأعمدة.
- كل حركة صرف أو إرجاع بتتسجل في صف جديد، والسجل القديم مبيتمسحش.
- لو مفيش ربط، البرنامج بيشتغل "محلي" على المتصفح بس.
